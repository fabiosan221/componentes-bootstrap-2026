Estructura inicial de plantilla HTML

Copia y pega este código en tu editor para comenzar un proyecto con Bootstrap 5.3.

1 <!doctype html>
2 <html lang="en">
3 <head>
4 <meta charset="utf-8">
5 <meta name="viewport" content="width=device-width, initial-scale=1">
6 <title>Bootstrap demo</title>
7 <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css" rel="stylesheet" integrity="sha384-sRIl4kxILFvY47J16cr9ZwB07vP4J8+LH7qKQnuqkuIAvNWLzeN8tE5YBujZqJLB" crossorigin="anonymous">
8 </head>
9 <body>
10 <h1>Hello, world!</h1>
11 <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js" integrity="sha384-FKyoEForCGlyvwx9Hj09JcYn3nv7wiPVlz7YYwJrWVcXK/BmnVDxM+D2scQbITxI" crossorigin="anonymous"></script>
12 </body>
13 </html>

Grilla

Hay 12 columnas de plantilla disponibles por fila, lo que le permite crear diferentes combinaciones de elementos que abarcan cualquier número de columnas. Las clases de columnas indican la cantidad de columnas de plantilla a abarcar (por ejemplo, col-4 abarca cuatro columnas para un elemento). Las columnas se pueden combinar para crear diferentes anchos de columna. Por ejemplo, tres elementos col-4 se alinearán en una fila, mientras que dos elementos col-6 se alinearán en otra fila.
